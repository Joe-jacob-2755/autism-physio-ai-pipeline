## EDA — Electrodermal Activity

### Physical Meaning

EDA (also called Galvanic Skin Response or Skin Conductance) measures the electrical conductance of the skin. It is driven entirely by the eccrine sweat glands, which are innervated exclusively by the sympathetic branch of the autonomic nervous system. EDA is therefore a direct, unambiguous marker of sympathetic arousal.

In autistic children, EDA has been shown to have:
- Higher baseline tonic levels in anxiety-provoking settings
- Larger and more frequent SCRs in response to sensory stimuli
- Slower recovery from phasic responses

### Two-Component Model

**Tonic (SCL — Skin Conductance Level):**
The slow baseline level of conductance. Changes over seconds to minutes. Reflects sustained sympathetic activation, emotional state, and thermoregulation.

**Phasic (SCR — Skin Conductance Response):**
Fast transient responses superimposed on the tonic. Each SCR follows a biphasic time course: rapid rise (0.5–4 s onset) followed by slow decay (5–30 s). SCRs can be stimulus-locked (event-related SCR, ER-SCR) or spontaneous (non-specific SCR, NS-SCR).

### Simulation Model

```
EDA(t) = SCL(t) + Σ SCR_i(t)

SCL(t)   = tonic_mean + slow_drift(t) + spontaneous_SCR_background(t)
SCR_i(t) = A_i · (1 − e^{−t/τ_rise}) · e^{−t/τ_decay}  [onset at t_i]
```

### Baseline Parameters

| Parameter | Value | Meaning |
|-----------|-------|---------|
| Tonic mean | 3.0 µS | Resting skin conductance level |
| Tonic std | 0.4 µS | Subject-to-subject variability |
| Drift amplitude | 0.6 µS | Slow ultradian oscillation amplitude |
| Drift frequency | 0.004 Hz | ~4-minute oscillation cycle |
| Spontaneous SCR rate | 0.05 /s | 3 spontaneous SCRs per minute at rest |
| Spontaneous SCR amplitude | 0.15 µS | Small background SCR magnitude |
| τ_rise (all SCRs) | 0.5 s | Standard EDA rise time constant |
| τ_decay (all SCRs) | 5.0 s | Standard EDA decay time constant |

## BVP — Blood Volume Pulse

### Physical Meaning

BVP (Blood Volume Pulse) is measured by photoplethysmography (PPG): an LED illuminates the skin and a photodetector measures the absorption, which changes rhythmically with blood flow during each heartbeat. The signal reflects cardiac activity and peripheral vascular tone.

### Waveform Features

Each cardiac cycle in the BVP contains:
- **Systolic peak** — maximum blood volume during ventricular ejection
- **Dicrotic notch** — brief dip caused by aortic valve closure
- **Diastolic peak** — secondary pressure wave from aortic recoil

### Simulation Model

```
BVP(t) = Σ template(t − t_i, RR_i, A_i)    [sum over all beats i]

template(t, RR, A) = G1(t,RR) + G2(t,RR) + G3(t,RR)

G1 = A       · exp(−(t'−0.18)² / 2·0.06²)   [systolic]
G2 = −0.12A  · exp(−(t'−0.42)² / 2·0.03²)   [dicrotic notch]
G3 = 0.30A   · exp(−(t'−0.54)² / 2·0.08²)   [diastolic]

t' = t / RR   [normalised beat time, 0–1]
```

### Baseline Parameters

| Parameter | Value |
|-----------|-------|
| Resting HR | 75 bpm |
| HR variability | ±3 bpm |
| Amplitude | 100 nT |
| Sensor noise | 4 nT std |

### Emotion-Specific Modulation

| Emotion | HR Δ (bpm) | HRV Factor | Amplitude Factor |
|---------|-----------|-----------|-----------------|
| Happy | +8.0 | 1.10 | 1.08 |
| Anger | +28.0 | 0.52 | 1.30 |
| Fear | +36.0 | 0.42 | 1.20 |
| Disgust | +10.0 | 0.80 | 1.05 |
| **Sad** | **−10.0** | **1.38** | **0.88** |

> HRV Factor < 1 = reduced heart rate variability (sympathetic dominance, stress). HRV Factor > 1 = increased variability (parasympathetic dominance, relaxation).

## IBI — Inter-Beat Interval

### Physical Meaning

IBI (also called RR interval or NN interval in clinical contexts) is the time elapsed between consecutive heartbeats, measured in milliseconds. It is the primary measure for Heart Rate Variability (HRV) analysis. IBI is not uniformly sampled — it is an event-based series with one value per detected beat.

### Clinical Significance

- **Short IBI** → fast HR → sympathetic activation (stress, arousal, exercise)
- **Long IBI** → slow HR → parasympathetic dominance (relaxation, sleep, fatigue)
- **High IBI variability (HRV)** → healthy autonomic flexibility
- **Low HRV** → reduced autonomic adaptability; associated with anxiety and stress in autism

### Simulation Model

```
RR_n = µ_RR + φ·(RR_{n-1} − µ_RR) + ε_n

µ_RR = 60,000 / HR_bpm    (ms)
φ    = 0.55                (AR coefficient — short-range HRV correlation)
ε_n  ~ N(0, σ_RR)          σ_RR = SDNN_ms / 1000
```

### Baseline Parameters

| Parameter | Value |
|-----------|-------|
| Mean IBI | 800 ms (75 bpm) |
| SDNN | 28 ms |
| AR(1) coefficient | 0.55 |
| Physiological range | 300–1500 ms (40–200 bpm) |

### Storage Format

IBI is stored as event-based timestamps (not uniform grid). In `combined_signals.csv`, it appears as a sparse column that is `NaN` between beats.

## ST — Skin Temperature

### Physical Meaning

Skin temperature at the wrist reflects peripheral vascular tone. Vasoconstriction (blood vessels narrowing) causes skin cooling; vasodilation causes warming. The sympathetic nervous system controls both via α-adrenergic receptors.

**Key physiological effects:**
- **Fear / Anger (acute stress):** Initial vasoconstriction → cold hands and wrist (well-known "cold sweat")
- **Sadness / Tiredness:** Mild vasoconstriction from reduced sympathetic tone
- **Happy / Anger (sustained):** Eventual vasodilation from increased metabolic demand → warming
- **Dehydration (Thirst):** Elevated skin temperature from reduced sweating and peripheral blood pooling

### Simulation Model

```
ST(t) = ST_baseline + ΔST_event(t) + slow_drift(t) + noise(t)

ΔST_event(t) = Δ_target · (1 − e^{−rate·t})

ST_baseline  = 33.0°C + N(0, 0.4)   (subject variability)
slow_drift   = 0.12 · sin(2π·0.002·t + φ)
noise        = N(0, 0.02)
```

### Baseline Parameters

| Parameter | Value |
|-----------|-------|
| Mean wrist temperature | 33.0°C |
| Subject variability | ±0.4°C |
| Slow drift amplitude | 0.12°C |
| Slow drift frequency | 0.002 Hz (~8 min cycle) |
| Sensor noise | 0.02°C std |

### Emotion-Specific Modulation

| Emotion | ΔT (°C) | Approach Rate (°C/s) | Physiological Mechanism |
|---------|---------|---------------------|------------------------|
| Happy | +0.20 | 0.04 | Mild vasodilation |
| Anger | +0.60 | 0.10 | Strong cutaneous vasodilation |
| **Fear** | **−0.65** | **0.12** | Peripheral vasoconstriction (cold extremities) |
| Disgust | −0.20 | 0.04 | Mild vasoconstriction |
| Sad | −0.30 | 0.025 | Reduced sympathetic tone → mild cooling |
| Surprise | +0.10 | 0.20 | Brief vasodilation (orienting response) |
| Hunger | −0.10 | 0.015 | Mild reduction in peripheral perfusion |
| **Thirst** | **+0.40** | **0.020** | Dehydration → peripheral pooling + heat retention |
| Toilet | +0.05 | 0.020 | Minimal thermal change |
| **Tired** | **−0.50** | **0.018** | Fatigue → hypothermia tendency |

## Accelerometer (ACC_X, ACC_Y, ACC_Z)

### Physical Meaning

The 3-axis accelerometer measures linear acceleration at the wrist. At rest it primarily measures gravity (9.81 m/s², normalised to 1 g). During activity it captures movement, and it always contains a small respiratory artefact from chest/wrist motion during breathing.

### Wrist Orientation Convention

| Axis | Resting Mean | Primary Physical Influence |
|------|-------------|---------------------------|
| ACC_X | ~0.02 g | Slight forward wrist tilt |
| ACC_Y | ~0.00 g | Lateral tilt (minimal at rest) |
| ACC_Z | ~0.98 g | Gravity (dominant) |

### Simulation Model

```
ACC_i(t) = gravity_i + breathing_i(t) + activity_i(t) + noise_i(t)

breathing_i(t) = A_breath · sin(2π·0.25·t + φ_i)    [A_breath = 0.04 g, ~15 breaths/min]

activity_i(t)  = envelope(t) · [A_act · sin(2π·f_act·t) + jitter(t)]
envelope(t)    = smooth tanh onset/offset ramp
```

### Emotion-Specific Motion Profiles

| Emotion | Activity Amp (g) | Dominant Freq (Hz) | Jitter (g) | Motion Description |
|---------|-----------------|-------------------|-----------|-------------------|
| Happy | 0.35 | 1.5 | 0.08 | Light rhythmic movement |
| Anger | 1.80 | 3.5 | 0.45 | Agitated, rapid movement |
| **Fear** | **0.90** | **9.0** | **0.25** | High-frequency tremor |
| Disgust | 0.28 | 1.0 | 0.10 | Mild aversive movement |
| **Sad** | **0.08** | **0.35** | **0.025** | Near-stillness |
| Surprise | 1.30 | 2.5 | 0.38 | Startle/jerk response |
| Hunger | 0.30 | 1.2 | 0.12 | Restless fidgeting |
| Thirst | 0.25 | 1.0 | 0.10 | Mild restlessness |
| Toilet | 0.65 | 2.2 | 0.22 | Squirming, weight shifting |
| **Tired** | **0.04** | **0.20** | **0.012** | Near-stillness / head drooping |

> **Fear at 9 Hz:** High-frequency tremor is physiologically characteristic of acute fear response. Normal voluntary movement is 1–4 Hz; pathological tremor from ANS activation is 8–12 Hz.

### Cross-Axis Correlation

Noise injection adds a 10% common-mode vibration component shared across X, Y, and Z axes, simulating realistic device vibration artefacts that appear correlated across channels.

## Signal Relationships and Correlations

The five modalities are not independent — they share common autonomic drivers.

| Relationship | Mechanism |
|---|---|
| EDA ↑ and HR ↑ | Both driven by sympathetic activation |
| EDA ↑ and HRV ↓ | Sympathetic dominance suppresses vagal influence on HR |
| EDA ↓ and HR ↓ | Parasympathetic dominance (Tired, Sad) |
| ST ↓ and HR ↑ | Acute stress: peripheral vasoconstriction + cardiac acceleration |
| ST ↑ and ST(dehydration) | Thirst: opposite mechanism — heat retention |
| ACC ↑ and HR ↑ | Physical activity drives both simultaneously |
| ACC tremor and EDA ↑ | Fear produces both high-freq tremor and maximal EDA response |

These correlations are implicitly preserved in the simulation because all signals share the same event timeline and are modulated by the same emotion profile parameters.
